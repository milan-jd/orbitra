# Orbitra: concept website

A one-page WebGL site for a fictional satellite-data company. It is a portfolio piece by **Milan John Davis**.

**Live site:** https://milan-jd.github.io/orbitra/

## What it shows

- A 3D planet drawn live in WebGL with Three.js: 30,000 particles, a 48-satellite constellation, orbit rings and inter-satellite links.
- A scroll-driven camera: the planet moves, scales and dims as you pass each section.
- An interactive simulator: drag the slider to add satellites and switch the planet between natural, thermal and vegetation views.
- A live-style dashboard: streaming chart, event feed and animated counters.
- Custom cursor, magnetic buttons, split-text reveals, a loader, and a mobile layout.

## A reference build

This site is intentionally a minimal showcase. Client projects build on this foundation with richer scenes, deeper interactivity, real data and custom features, all scoped to each brief.

## Run locally

Serve the folder with any static server (for example `python3 -m http.server`) and open it in a browser. `app.js` is the bundled build.
